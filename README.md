# Vouch — legal pages

The privacy policy for the [Vouch](https://github.com/melihdikmen/vouch) app, served by
GitHub Pages so the app stores have a publicly reachable URL to point at.

**Live:** https://melihdikmen.github.io/vouch-legal/

This repository is public on purpose and holds nothing but the page. The app itself stays
private. `index.html` is generated from `docs/privacy-policy.md` in the app repo — edit it
there first, so the policy and the code it describes stay in step.
